# 🚀 Task 1 — Weather Web Application

## 📖 Description
A responsive weather application that fetches and displays live weather information using the Open-Meteo API.

The application allows users to search weather details by entering city names and dynamically displays:
- Temperature
- Wind Speed
- Time
- Weather Conditions

The project focuses on API integration and responsive UI development.

---

## ✨ Features
- Real-time weather data
- City-based weather search
- Dynamic API fetching
- Responsive UI
- Interactive weather cards
- Error handling
- Loading effects
- Modern design

- JavaScript
- Open-Meteo API
